# What we lose when tools decide the task

The idea that tools shape thought is old, but software makes it literal. When we automate a task we also fix what counts as the task, and that definition outlives the code that enforced it.

A spreadsheet does not just add numbers faster; it makes some questions easy to ask and others invisible. The danger is not that the tool is wrong, but that its defaults become the shape of the work, unquestioned, long after anyone remembers choosing them.
